## 0. Reading order and drift warnings

1. Jev (`typesafe/jev-1.13` Decisions API) is the ONLY decision engine in production. Models (OpenRouter/Anthropic text) are used only for banter via `talk`. The old zod/`generateObject` move path, `L0_BID`/`L0_PLAY` decision prompts, prompt-cache layers and the Opus/Haiku tiers (`MODEL_PLAY` claude-haiku-4-5, `MODEL_BID` claude-opus-5 in `src/lib/protocol/index.ts`) are legacy and only survive in the conversation prompt path (`ai/prompt.ts`, used by banter). Do not port the legacy decision path.
2. Two overlapping ladders exist: `decide()` in `src/lib/ai/decide.ts` (budgets from `ai/config.ts`: 6500/3000/400/600 ms) and `runLadder()` in `src/lib/actors/ai-seat/decide.ts` (budgets from `ai-seat/types.ts`: 2200/1400/400/300 ms). Production uses the actor ladder, which calls `callModel` from `ai/decide.ts`. Port the actor ladder constants; port `callModel` composition.
3. `callModel` ignores its `escalate` argument. "Escalation" attempt 2 is an identical Jev call (a plain retry).
4. Two screens: `ai/screen.ts` (bower detection + table_advice; used by banter) and `ai-seat/screen.ts` (rationale cleaning, `publicOnlyView`, `sanitizePersona`). Port both; keep distinct functions.
5. Unused: `memoryLines` in `DecideDeps`, `BANTER_MAX_PER_TRICK`, `BANTER_MAX_PER_HAND`, `BANTER_COOLDOWN_MS` (defined in `ai-seat/types.ts`, not enforced). Real banter gate: one per hand via `banter.lastHandNo`.

## 3. Decision ladder (actor, `src/lib/actors/ai-seat/decide.ts` `runLadder`)

Order:
1. **forced**: exactly one legal move -> return it, rationale fixed, no log noise.
2. **degraded** circuit breaker (`state.degraded`): skip the model, heuristic top-1.
3. **Candidates**: full legal set for play/bid1/bid2 (narrowing never applied there); narrowed only for cut/discard via `narrowByDifficulty` (section 12).
4. `resolveDecider()` returns null (no provider) -> heuristic, log `ai_no_provider`.
5. Attempts: `[false]` for play, `[false, true]` for other kinds. Each attempt: `budgetFor = min(nominal, deadlineAt - now - DEADLINE_RESERVE_MS(300))`; if `< LLM_MIN_ATTEMPT_MS(400)` log `ai_no_budget` and stop. Nominal = LLM_FIRST_ATTEMPT_MS 2200 for attempt 1, LLM_ESCALATION_MS 1400 for attempt 2.
6. Failure (timeout, `jev_failure`, error) -> log `ai_attempt_failed`, continue to next attempt if `shouldContinueAfter` says so (ai/decide.ts: NoObjectGenerated -> continue; APICallError -> only if retryable; Timeout/Abort -> continue; else stop).
7. Returned id not in the legal set -> log `ai_illegal_id`, treat as failure.
8. Fallback: heuristic top-1 (`rankingFor`: use supplied ranking iff same length and all ids legal, else `rankMoves` with persona aggression/risk), confidence 0.5, rationale sliced to 120 (`heuristicOutcome`). Ties ordered by id ascending.
9. Model rationale is passed through `cleanRationale` (ai-seat/screen.ts); empty -> heuristic `why` fallback.

Constants (`ai-seat/types.ts`): MEM_TRUMP_SEEN_CAP 7, MEM_VOID_SUITS_CAP 3, MEM_LEAD_CAP 5, MEM_BID_CAP 8, MEM_NOTE_CAP 8, NOTE_MAX_CHARS 140, EPISODE_BUFFER_CAP 12, LATENCY_SAMPLE_CAP 32, DECISION_LOG_CAP 24, BUDGET_INPUT_TOKENS 250000, BUDGET_OUTPUT_TOKENS 20000, BUDGET_CALLS 300, BANTER_BUDGET_MS 1800.

Alternate `decide()` (`ai/decide.ts`): same rungs, DEFAULT_CONFIDENCE 0.6, `NoLegalMovesError`, `remaining = min(budgetMs, deadlineAt-now)`, throws TimeoutError DOMException if `<=0`. `ai/config.ts` defaults: firstAttemptMs 6500, escalationMs 3000, reserveMs 400, minAttemptMs 600, banterMs 4000, maxOutputTokens bid 1600 / play 1200 / banter 800; `tierOf`: play fast, else deliberate; `allowsEscalation = isDeliberate`. Keep as a config module but production path uses the actor constants.

Table-side timing (context only, `euchre-table/tempo.ts`): thinkFloorMs cut 700, bid1 1900, bid2 1900, discard 1100, play 1000, + fnv1a jitter up to 400; `aiHardCapMs` 4000 (`deadlineAt = now + 4000`); `aiExtendedAtMs` 2200; `EUCHRE_FAST_TEMPO=1` scales down.

## 4. Jev Decisions API contract (`src/lib/ai/jev.ts`)

- Request: `POST {base}/alpha/decisions`.
  `base` = `OPENROUTER_BASE_URL` (default `https://openrouter.ai/api/v1`), strip trailing `/`, then strip a trailing `/v1` => `https://openrouter.ai/api`.
- Headers: `Authorization: Bearer <OPENROUTER_API_KEY>`, `Content-Type: application/json`.
- Body: `{"model":"typesafe/jev-1.13","state":<object>,"questions":{...additionalQuestions,"move":{"type":"choice","instructions":<string>,"criteria":{<key>:<description string>}}}}`.
- Response (validate with serde + manual checks):
  `{id?, model?, answers:{<qid>:{type:"choice", choice:string, confidence:0..1, probabilities:{<key>:0..1}}}, usage:{input_tokens, output_tokens}}`.
- Per-question validation, in this order; failure => `JevDecisionError{reason:"choice_distribution", detail}`:
  1. `missing_answer`
  2. `unknown_choice` (choice not in criteria keys)
  3. `option_keys` (probability key set != criteria key set)
  4. `probability_total` (`|sum-1| > 0.02`)
  5. `choice_not_maximum` (any probability exceeds the chosen one's by `> 1e-6`)
- `JevDecisionError.reason`: `http_status` (non-2xx; body NEVER retained, only status), `response_schema` (parse/shape), `choice_distribution`.
- No retries. Caller's abort signal cancels the request (use `tokio::select!` with a cancellation token / `tokio::time::timeout`; a cancelled call must not send). Usage returned as `{input, output, cacheRead:0, cacheWrite:0}`.
- Text-only providers (Anthropic key) have no `decision` capability: `modelFactoryFromEnv` returns a factory without `decision`, so ladder falls to heuristic. Legacy model env overrides never enable decisions.
- `callDecider` (`llm-bridge.ts`) logs `jev_failure` with `reason`, `status`, `diagnostic` on failure; `withDeadline` rejects with `llm_timeout`.

### 4.1 `callModel` composition (`ai/decide.ts`)

1. `buildDecisionQuestion(view, legal, persona)` -> `{state, criteria, choices, aloneChoices, bidChecks, additionalQuestions, instructions}`.
2. Call Jev. Chosen key `move_i` -> choice index.
3. Voluntary bids: `bidChecks[move_i]` names a `support_i` pass/call sub-question. If its answer is `pass`, drop that move and pick the highest-probability supported move among the rest (or pass if none).
4. Loner: sub-question `loner_i` (`partner`/`alone`) picks the alone vs partner variant of the move id.
5. Rationale = heuristic `why` for the chosen move; confidence = Jev's `confidence` for the final answer. Log event `jev_decision`.

## 5. Decision-context builder (`ai/decision-context.ts`, 452 lines)

`DECISION_PROMPT_VERSION = "jev-euchre-2"`.
`buildDecisionQuestion`:
- `choices`: legal moves in `legal` order, dropping any alone variant that has a non-alone twin; keys `move_0..move_n`.
- `auctionHands`: keyed by `SUIT_NAME`, per possible trump suit the explicit holding, outside aces and dealer pickup outcomes (`biddingOption`, `holdingFacts`, `cardFact`).
- `additionalQuestions`: `support_i` and `loner_i` (see 4.1); `aloneChoices` maps loner keys; `bidChecks` maps move key to support key.
- `state`: object of public view + `table` (tableContext) + `partnership` + `ownHolding` + rollouts (`referenceWithPartner`, `referenceAlone`, `referenceContinuation`) + `dominantLonerKeepAfterPickup`.
- Persona influence: ONLY aggression <0.4 / >0.65 and risk <0.4 / >0.65 produce a style string; no persona text is sent to Jev.
- Instruction selection: bidding phases -> BID; `dealer_discard` -> DISCARD; `cutting` -> inline cut string; trick empty -> LEAD; else PLAY.

## 7. Rollouts and RNG

### 7.1 RNG (`bid-rollouts.ts`/`play-rollouts.ts` `randomFor`)
```
seed = 2166136261 (u32)
for each UTF-16 code unit c of text: seed = imul(seed ^ c, 16777619)   // u32 wrapping
// then Mulberry32 stream from seed (same mulberry32 as engine: a += 0x6D2B79F5 ... >>>)
```
Hash over UTF-16 code units, not bytes or chars (use `str.encode_utf16()`). All arithmetic wrapping `u32`; `>>> 0` = `as u32`. Float output `((t ^ (t >>> 14)) >>> 0) / 4294967296`. Seed text is a function of PUBLIC state only (see tests "cannot read private cards or seeds"): copy the exact seed-string template from the TS.

### 7.2 Bid rollouts (`ai/bid-rollouts.ts`)
- `BID_ROLLOUT_SAMPLES = 32`.
- Per sample: Fisher-Yates shuffle of the unseen cards (public: not in own hand, not turned-down up-card unseen only when public), deal to the other three hands, put the up-card with the dealer when relevant; for each candidate move play out to `hand_score` using `topMove` (heuristic) for all seats, max 40 steps, through engine `createGame`, `apply`, `advance`, `project`.
- Point model: maker loses 2 on euchre (own team -2), 1 for 3-4 tricks, 4 for alone-march or 2 for normal march. Output per move: mean net points, make rate, sweep rate (`referenceWithPartner` / `referenceAlone`).
- Assessment thresholds 0.5 / 0.7 / 0.85 map to wording labels (copy from source).
- Independent of option order; does not depend on unknown deck order, private seed or another hand.

### 7.3 Play rollouts (`ai/play-rollouts.ts`)
- `PLAY_ROLLOUT_SAMPLES = 24`, up to 512 attempts to build each consistent sample, constrained by proved voids and by the up-card staying with the dealer or being discarded (dealer sits out on partner loner: up-card buried).
- Each option is played out with `topMove`; result is `referenceContinuation {meanTeamPoints, teamTricks...}` using maker points.
- Returns nothing for forced moves or incomplete fixtures. Never mutates the view.

## 14. aiSeat actor (`src/lib/actors/ai-seat/index.ts`, 659 lines)

- Registry name: `aiSeat` (options `{name:'AI Seat', icon:'robot'}`). Key: `["table", gameId, "seat", "1"|"2"|"3"]`. Created by table with `createWithInput: AiSeatCreateInput` (`euchre-table/index.ts` 728-770; includes `fenceNonce` derived from matchId, persona, difficulty, internal token).
- Queues: `decide`, `resetHand`, `handEnd`, `gameEnd`. Single run loop with a completable iterator; one message at a time.
- Actions: `getStatus` (AiStatus incl. latency p95 = `sorted[ceil(n*0.95)-1]`, budget meter, degraded flag), `getPersona`, `getDecisionLog` (ring of 24 `DecisionRecord`).
- State `AiSeatState {schema:1, persona, difficulty, memory, episodes[], budget(AiSeatBudget), meter, banter{lastHandNo}, decisionLog[], lastTurnId, degraded, latencySamples[32]...}`; `blankPersona`.
- `onDecide` flow: (1) constant-time compare `internalToken` (reject otherwise), (2) check gameId, seat, `lastTurnId` (idempotent: drop duplicate turnId), (3) `absorbPublicState`, (4) `runLadder`, (5) `recordDecision` + `applyUsage` (input/output tokens, calls vs BUDGET_*; over budget flips `degraded`), (6) `saveState({immediate:true})`, (7) `getOrCreate(['table', gameId], {params:{internalToken}}).send('aiDecision', AIDecision)`, (8) optional banter via `waitUntil`: requires writer present, not degraded, chattiness > 0, `banter.lastHandNo !== handNo`, `trump !== null`; sends `aiSay` with `msgId = \`${turnId}:talk:${seat}\``, `final:true`, `budgetMs 1800`.
- `onResetHand`: `resetMemory`; `onHandEnd`: `rememberHand`, push episode, `flushEpisodes`; `onGameEnd`: `flushEpisodes` + `flushTokens`.
- `flushEpisodes` -> playerProfile action `recordEpisodes`; `flushTokens` -> `recordTokens`; both authenticated with `EUCHRE_INTERNAL_TOKEN` (>=16 chars; dev fallback `euchre-dev-insecure-secret` only when `RIVET_ENDPOINT` unset).
- Table side authorizes with `tokenOk` (`euchre-table/queues.ts`); `aiDecision`/`aiSay` queues have `canPublish: externalDenied`. Table drops late/illegal/forged decisions and falls back to its parked heuristic move (table holds no heuristic of its own beyond that parked move).
- Workflow steps: the TS actor uses a queue run loop, not rivetkit `workflow()`; each handler step is: validate -> compute -> save(immediate) -> send. Preserve that ordering (state is durable before the reply is sent so a crash after save re-sends idempotently via `lastTurnId`).

## 18. Porting hazards

1. JS number semantics: `Math.imul`, `>>> 0`, `toFixed`, `Math.round(x*100)/100` in strings sent to Jev; any difference changes prompt JSON and RNG streams.
2. UTF-16 hashing for `randomFor`/`fnv1a` (not UTF-8).
3. JSON key order in Jev `state` (serde_json with `preserve_order`); numeric formatting (`1` vs `1.0`) - Jev does not care but golden tests will.
4. Regexes with lookaround and Unicode classes (`GLYPH_RE`, bidi) - verify `regex` crate support.
5. AbortSignal -> `CancellationToken`/`tokio::time::timeout`; cancelled call must not issue the HTTP request.
6. ai-sdk is NOT needed for Jev (plain HTTP). Banter streaming needs an OpenRouter/Anthropic chat-completions SSE client (`streamText` equivalent) with per-chunk screening.
7. Constant-time token compare (`subtle` crate).
8. Rollouts cost: 32 x candidates x up to 40 engine steps per bid; 24 x options per play. Run on a blocking thread pool within the 2200 ms budget; heuristic engine must be allocation-light.
9. Parity of engine behaviour (rollouts call the engine) - the engine crate must pass its own goldens first.
